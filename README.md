# Customer Shopping Behaviour Analysis

## Project Overview
This project explores customer shopping behaviour and purchasing patterns using Power BI. The dashboard provides insights into customer preferences, purchase trends, and shopping habits.

## Objectives
- Analyse customer purchasing behaviour.
- Identify customer preferences and trends.
- Understand purchasing patterns.
- Present insights through interactive dashboards.

## Tools & Technologies
- Microsoft Power BI
- Data Analysis
- Data Visualization

## Key Features
- Interactive dashboards
- KPI visualizations
- Customer behaviour analysis
- Shopping pattern insights

## Project Files
- Power BI Dashboard (.pbix)
- Project Report
- Dashboard Screenshots

## Outcome
Developed an interactive Power BI dashboard to analyse shopping behaviour and transform raw data into meaningful business insights.
